SOBRE O PROJETO

Construída com transparência.

O que esta versão faz

  • Servidor Node.js sem dependências externas obrigatórias.
  • Chat ligado à API de IA quando a chave é configurada no servidor.
  • Importação CSV/JSON e cálculos numéricos locais no navegador.
  • Endpoint de telemetria para receber valores numéricos.
  • Interface responsiva com navegação entre módulos.

O que ainda não está pronto para produção

  • Login, contas, permissões e separação de dados por usuário.
  • Banco de dados persistente, histórico de conversas no servidor e armazenamento de arquivos.
  • Integração física com sensores, gateways ou modelos Edge locais.
  • Proteções avançadas de produção: limites por usuário, monitoramento, testes de carga e revisão de segurança.

Esta versão é um MVP para testar fluxos. Não use dados confidenciais nem publique como serviço multiusuário antes de implementar autenticação e controles adicionais.
